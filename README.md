# NAARAD
apps/ holds your deployable applications. The pwa/ is your immediate focus — this is where your service worker, manifest, and frontend framework live. api/ is the backend when you're ready. Each app has its own package.json, its own build config, and deploys independently.
packages/ holds code shared across apps. ui/ for reusable components (buttons, layouts, etc.), shared/ for TypeScript types, validation schemas, API contracts, and utility functions, and config/ for centralized ESLint/Prettier/TypeScript configs so every app stays consistent without duplicating rules.
Tooling recommendation: Use pnpm workspaces + Turborepo for this. pnpm gives you fast installs with a single lockfile, and Turborepo gives you smart caching — it only rebuilds packages that actually changed. The pnpm-workspace.yaml just points to apps/* and packages/*.
